---
name: Three-Sentence Method
description: Product direction for how Listening Notebook teaches and applies the Three-Sentence Method.
---

The Three-Sentence Method is a centerpiece of Listening Notebook's description workflow. Its three jobs are evidence (what happens), experience (how the space unfolds), and intention (why this stretch was kept). Treat the method as a flexible starting point, not a rigid length rule.

**Why:** The user explicitly asked to make the method central to the app. Keep the draft distinct from the saved session description so existing Library text is not replaced until the user chooses to apply it.

**How to apply:** Keep the three method prompts prominent in Description Builder, autosave their draft separately, provide a deliberate action to apply it to the session description, and preserve it in backups and human-readable exports.
